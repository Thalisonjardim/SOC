## Professional focus

I am developing practical defensive cybersecurity skills through hands-on laboratories, technical investigations and reproducible documentation. My goal is to combine strong security fundamentals with responsible AI-assisted workflows to become a more effective security professional.

## Evidence-first, AI-augmented security

- **Hands-on practice:** collect evidence, operate security tools and investigate events in authorized environments.
- **AI augmentation:** use AI to explore hypotheses, explain unfamiliar behavior, improve workflows and support technical documentation.
- **Human verification:** check AI-generated claims against packet captures, logs or other primary evidence; label uncertainty and avoid unsupported conclusions.
- **Privacy and ethics:** redact sensitive identifiers, protect credentials and keep testing within authorized environments.

AI is a tool for improving analytical capability, not a substitute for technical understanding or accountability. Each case study documents the scope of practical work and AI assistance where relevant.
